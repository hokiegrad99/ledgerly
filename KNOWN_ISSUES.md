# KNOWN_ISSUES.md — Bugs, Limitations, Incomplete Functionality

Statuses: `OPEN`, `IN_PROGRESS`, `FIXED`, `VERIFIED`, `WONT_FIX`, `DEFERRED`.
Never silently ignore known problems — log them here.

## ISSUE-001
- **Title:** Budget rollover carry-forward is stored but not computed
- **Severity:** Medium
- **Status:** OPEN
- **Affected requirement:** REQ-026
- **Steps to reproduce:** Mark a category with "rollover", end a month under budget,
  move to the next month — the unused amount is not added to next month's budget.
- **Expected:** Unused budget with rollover=true carries forward.
- **Actual:** The flag is persisted; carry-forward math is not implemented.
- **Proposed fix:** In `budgetSummary` or the Budget page, compute previous month's
  remaining (only rollover items) and add to current month's budgeted value; add tests.

## ISSUE-002
- **Title:** PWA offline behavior verified only at build level
- **Severity:** Medium
- **Status:** OPEN
- **Affected requirement:** REQ-041
- **Steps to reproduce:** Deploy to GitHub Pages, install the app, go offline, reload.
- **Expected:** App loads and core functionality works offline.
- **Actual:** Service worker and manifest are generated by `vite-plugin-pwa`; live
  offline verification has not been performed.
- **Proposed fix:** Deploy, test offline in browser, adjust `workbox` globPatterns
  if assets are missing.

## ISSUE-003
- **Title:** Transaction search does not search tag names
- **Severity:** Low
- **Status:** OPEN
- **Affected requirement:** REQ-035
- **Steps to reproduce:** Search for a tag name (e.g. "Travel") in Transactions.
- **Expected:** Transactions with that tag appear.
- **Actual:** Search covers merchant/description/notes only; tag filtering is
  available via the tag filter dropdown but not free-text search.
- **Proposed fix:** Resolve tag names → ids in `queryTransactions` search path.

## ISSUE-004
- **Title:** Reports "category" filter select lists every category ungrouped
- **Severity:** Low
- **Status:** OPEN
- **Affected requirement:** REQ-033
- **Steps to reproduce:** Open Reports, open the category filter.
- **Expected:** Categories grouped by group.
- **Actual:** Flat list (functional, less scannable).
- **Proposed fix:** Render optgroups like the transaction filter.

## ISSUE-005
- **Title:** No undo for bulk delete
- **Severity:** Low
- **Status:** OPEN
- **Affected requirement:** REQ-014
- **Steps to reproduce:** Select many transactions, delete.
- **Expected:** Undo is available where practical.
- **Actual:** Deletion is immediate with a confirm dialog only.
- **Proposed fix:** Keep a short-lived in-memory undo buffer for deletes (restores
  transactions + splits + transfers).
